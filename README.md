# 🎟️ تيك تاك | TikTak - منصة بيع ومسح تذاكر الفعاليات الذكية

منصة متكاملة Full-Stack لإدارة وبيع وتدقيق تذاكر الفعاليات والمؤتمرات، موجهة ومصممة بالدرجة الأولى لتجربة فائقة السرعة على الهواتف الذكية (Mobile-First) وتعمل بكفاءة تامة على الأجهزة اللوحية وأجهزة الكمبيوتر، مع دعم كامل للغة العربية (RTL).

---

## 🚀 المميزات الرئيسية للمنصة

### 1. تجربة العميل / المشتري (Customer Experience):
- **تصفح واستكشاف الفعاليات**: استعراض الفعاليات حسب التصنيف (تقنية، أعمال، موسيقى، رياضة، فنون) والمدينة، مع محرك بحث فوري.
- **حجز مرن ومتعدد الفئات**: دعم فئات تذاكر متعددة لكل فعالية (VIP، تذاكر عامة، ورش عمل، دخول مبكر) مع حساب الأسعار وعدد المقاعد المتبقية فورياً.
- **إصدار تذكرة إلكترونية فريدة**:
  - تذكرة رقمية بتصميم مميز وبطاقة مرور تحمل شعار الفعالية واسم المشتري ونوع الفئة.
  - رمز QR فريد ومشفر لكل تذكرة مع رقم تسلسلي مستقل لمنع التزوير.
  - إمكانية **تحميل التذكرة كصورة عالية الدقة (PNG)** أو **مستند (PDF)**، أو **المشاركة عبر واتساب** أو **الطباعة**.
- **محفظة تذاكري**: قسم مخصص لعرض كافة التذاكر المشتراة والرجوع إليها في أي وقت.

### 2. لوحة تحكم المنظم (Organizer Dashboard):
- **إنشاء وتدشين الفعاليات**: إضافة عنوان الفعالية، الوصف، الشعار، البنر، الموقع، التواريخ، وتحديد فئات التذاكر وسعتها وأسعارها.
- **إحصائيات المبيعات والإيرادات**: متابعة حية لمبالغ المبيعات (ر.س)، عدد المقاعد المحجوزة، ونسبة الحضور الفعلي.
- **سجل الحضور والتذاكر الصادرة**: استعراض قائمة المشترين وتفاصيلهم مع إمكانية **تصدير ملف Excel / CSV** لبيانات الحضور.

### 3. نظام مسح وتدقيق التذاكر للبوابات (Ticket Scanning System):
- **ماسح QR مباشر عبر كاميرا الهاتف**: يعمل مباشرة من المتصفح مع دعم تبديل الكاميرات والوميض.
- **تحقق فوري من حالة التذكرة**:
  - 🟢 **تذكرة صالحة (Valid)**: تأكيد الدخول وتحديث سجل الحضور فوراً مع تنبيه صوتي واهتزاز haptic.
  - 🟡 **تذكرة ممسوحة مسبقاً (Already Used)**: تنبيه فوري يوضح توقيت واسم البوابة التي تم الدخول منها مسبقاً لمنع تكرار الدخول.
  - 🔴 **تذكرة غير صالحة / فعالية خاطئة (Invalid)**: جرس إنذار ورسالة تحذيرية.
- **إدخال يدوي بديل**: للتعامل مع الرموز التالفة أو شاشات الهواتف المكسورة.
- **عدادات الحضور الحية**: متابعة عدد الحاضرين والمتبقين ونسبة الحضور عند البوابة.
